Engram

In Cyberpunk 2077, an engram is a digital copy of a person's mind. This project builds a practical version, built from a lifetime of my personal data. It learns my voice from everything I have written: emails, chat messages across Messenger, WhatsApp and Telegram, social media posts, notes and code commits. Its memory draws on the rest of my digital trail, including my calendar, documents, location history, and the YouTube videos and websites I have watched and read over the years. It is trained entirely on my own hardware.

Voice

A QLoRA fine-tune of Qwen3 8B on messages I wrote myself: email replies, chats and posts. Training loss is applied only to my side of each conversation. Other people's messages appear only as the context I was replying to.

Memory

Next, a retrieval index over everything: mail, documents, calendar, notes and location history. The voice then has facts to talk about.

Data

  • Gmail, Calendar, Drive, YouTube, Chrome
  • Messenger, Instagram, WhatsApp, Telegram
  • X, LinkedIn, Reddit
  • Notes and git commit messages

Privacy

Everything stays local. Parsing runs on a Mac and training runs on one RTX 4080 Super. Passwords, codes and card numbers are redacted at parse time. The weights are never published, so the chat below talks to a model running on your own machine.

Settings

Serve the GGUF with Ollama and allow this origin: OLLAMA_ORIGINS=https://jach.me ollama serve
