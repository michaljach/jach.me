Engram

A digital copy of a person: an LLM trained on lifetime personal data from Gmail, Calendar, Drive, YouTube, Chrome, Messenger, Instagram, WhatsApp, Telegram, X, LinkedIn, Reddit, notes and git history.

How it works

  1. 01

    Export

    Download a lifetime of data from Google, Meta, WhatsApp, Telegram, X, LinkedIn and Reddit, plus notes and git history.

    data/raw/
  2. 02

    Ingest

    Parse every source into one format. Redact passwords, codes and card numbers. Drop newsletters and spam.

    messages.jsonl docs.jsonl
  3. 03

    Build

    Split chats into conversations. My replies become the training targets; everyone else's messages are only context.

    sft_train.jsonl
  4. 04

    Train

    QLoRA fine-tune of Qwen3 8B on a single RTX 4080 Super, then export for local inference.

    LoRA adapter GGUF
  5. 05

    Remember Next

    Index mail, documents, calendar, notes and location history so the model can recall real facts.

    retrieval index
  6. ◆

    Engram

    A model with my personality and, soon, my memory, running entirely on my own hardware.

Personality

A QLoRA fine-tune of Qwen3 8B on messages I wrote myself: email replies, chats and posts. Training loss is applied only to my side of each conversation. Other people's messages appear only as the context I was replying to.

Base model
Qwen3 8B
Method
QLoRA, 4-bit base
LoRA
rank 32, alpha 32, all attention and MLP projections
Context
4,096 tokens
Training
2 epochs, lr 1e-4 cosine, AdamW 8-bit, bf16
Batch
2 × 8 gradient accumulation
Stack
Unsloth, TRL, Hugging Face Datasets
Hardware
RTX 4080 Super, 16 GB
Export
LoRA adapter, GGUF Q4_K_M

Memory

Next, a retrieval index over everything: mail, documents, calendar, notes and location history. The model then has real facts to draw on.

Data

  • Gmail, Calendar, Drive, YouTube, Chrome
  • Messenger, Instagram, WhatsApp, Telegram
  • X, LinkedIn, Reddit
  • Notes and git commit messages

Privacy

Everything stays local. Parsing runs on a Mac and training runs on one RTX 4080 Super. Passwords, codes and card numbers are redacted at parse time. The weights are never published.
