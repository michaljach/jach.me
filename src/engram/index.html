Engram

Compress yourself into an AI Model trained on lifetime personal data from Gmail, Calendar, Drive, YouTube, Chrome, Messenger, Instagram, WhatsApp, Telegram, X, LinkedIn, Reddit, notes and git history.

Source code michaljach/soulkiller

How it works

  1. 01

    Export

    Download a lifetime of data from Google, Meta, WhatsApp, Telegram, X, LinkedIn and Reddit, plus notes and git history.

    data/raw/
  2. 02

    Ingest

    Parse every source into one format. Redact passwords, codes and card numbers. Drop newsletters and spam.

    messages.jsonl docs.jsonl
  3. 03

    Build

    Split chats into conversations. Your replies become the training targets; everyone else's messages are only context.

    sft_train.jsonl
  4. 04

    Train

    QLoRA fine-tune of Qwen3 8B on a single RTX 4080 Super, then export for local inference.

    LoRA adapter GGUF
  5. 05

    Remember Next

    Index mail, documents, calendar, notes and location history so the model can recall real facts.

    retrieval index
  6. ◆

    Engram

    A model with your personality and, soon, your memory, running entirely on your own hardware.

Model specs

Base model
Qwen3 8B
Method
QLoRA, 4-bit base
LoRA
rank 32, alpha 32, all attention and MLP projections
Context
4,096 tokens
Training
2 epochs, lr 1e-4 cosine, AdamW 8-bit, bf16
Batch
2 × 8 gradient accumulation
Stack
Unsloth, TRL, Hugging Face Datasets
Hardware
RTX 4080 Super, 16 GB
Export
LoRA adapter, GGUF Q4_K_M

Benchmarks

Personality

A QLoRA fine-tune of Qwen3 8B on messages you wrote yourself: email replies, chats and posts. Training loss is applied only to your side of each conversation. Other people's messages appear only as the context you were replying to.

Memory

Next, a retrieval index over everything: mail, documents, calendar, notes and location history. The model then has real facts to draw on.

Data

  • Gmail, Calendar, Drive, YouTube, Chrome
  • Messenger, Instagram, WhatsApp, Telegram
  • X, LinkedIn, Reddit
  • Notes and git commit messages

Privacy

Everything stays local: parsing and training run on your own hardware, and a single 16 GB GPU is enough. Passwords, codes and card numbers are redacted at parse time.
