Browser port test

Runs the golden vectors (models/jet/golden.json from jet-golden) through the in-browser model and compares prompts, token ids and answers with the MLX reference. Prompts and token ids must match exactly; logits only up to quantization error. ?model=<base url>&file=onnx/model_q8_compact.onnx&max=N pick what to test. States longer than the browser's limit (max, default 2048 tokens; the server uses 4096) are cut differently from the reference by design.

Not started. Downloads the model and runs the reference cases on your GPU.
